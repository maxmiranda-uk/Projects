# Pandas Data Analysis Practice

This repository contains my self-directed practice with Python and pandas, using real-world data from the UK Office for National Statistics (ONS).

I created this project while learning pandas independently, with the aim of developing my data handling, analysis and visualisation skills alongside my Physics degree.

## Dataset

The analysis uses the ONS Services Producer Price Inflation (SPPI) dataset for:

**Engineering Services & Related Services**

The dataset is included as `series-180126.csv`.

## What I Practised

The Python script covers a range of pandas techniques, including:

- Creating DataFrames and Series
- Reading and inspecting CSV data
- Selecting and filtering data
- Converting data types and handling invalid values
- Creating and renaming columns
- Calculating summary statistics
- Sorting and grouping data
- Reshaping data
- Working with quarterly time-series data
- Using a DatetimeIndex for date-based selection
- Creating visualisations with pandas and Matplotlib
